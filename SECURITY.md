# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest tagged release | Yes |
| Older releases | No |

Before the first release, fixes land on the default branch.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories:

<https://github.com/lintsinghua/oops/security/advisories/new>

Please include a description, the version or commit you tested, and a way to
reproduce the issue if you have one. Do not open a public issue for a
security report.

We will acknowledge reports that we can reproduce and use the advisory to
coordinate a fix.
