# @lintsinghua/oops

Ctrl+Z for Agent: precise undo and redo in one step.

The unscoped npm name `oops` is already registered, so this package is scoped.

```sh
npm i -g @lintsinghua/oops
npx @lintsinghua/oops
```

npm installs one optional platform package (`@lintsinghua/oops-<os>-<cpu>`) that already contains the binary. There is no postinstall download.

Next step: `oops init`
